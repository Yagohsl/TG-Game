### 🧠 Sobre o Projeto

O **Mindbound** é um jogo de luta 2D desenvolvido nativamente em Python com a biblioteca Pygame, concebido como Trabalho de Graduação. O projeto vai além do entretenimento tradicional, utilizando a interatividade dos videogames para abordar e debater um tema de extrema relevância social: a **saúde mental**.

### 🎯 O que é um Serious Game?

Um **Serious Game** (ou *Jogo Sério*) é um jogo projetado para um propósito primário que vai além do puro entretenimento — neste caso, a **educação e conscientização**. 

Em vez de apenas divertir, o *Mindbound* utiliza as dinâmicas clássicas de um jogo de luta como uma metáfora visual para os conflitos e batalhas internas que muitas pessoas enfrentam diariamente. Com essa abordagem, o projeto alinha-se diretamente aos **Objetivos de Desenvolvimento Sustentável (ODS) da Organização das Nações Unidas (ONU)**, mais especificamente ao **ODS 3: Saúde e Bem-Estar**, focado em promover a saúde mental e o bem-estar social.
